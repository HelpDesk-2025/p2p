ERROR: "Missing Supabase environment variables"

WHY: Environment variables NOT set in Azure App Service

═══════════════════════════════════════════════════════════════════

STEP 1: Get Supabase Credentials (2 minutes)
──────────────────────────────────────────────

1. Go to: https://app.supabase.com
2. Select your project
3. Settings → API
4. Copy:
   - Project URL (https://xxxxx.supabase.co)
   - anon public key (eyJhbGc...)

═══════════════════════════════════════════════════════════════════

STEP 2: Set in Azure Portal (3 minutes)
────────────────────────────────────────

1. Go to: https://portal.azure.com
2. Find your App Service
3. Configuration → Application settings
4. Click "+ New application setting" three times:

   Setting 1:
   Name:  VITE_SUPABASE_URL
   Value: [paste your Project URL]

   Setting 2:
   Name:  VITE_SUPABASE_ANON_KEY
   Value: [paste your anon key]

   Setting 3:
   Name:  NODE_ENV
   Value: production

5. Click SAVE (top of page)
6. Click CONTINUE
7. Wait 2 minutes

═══════════════════════════════════════════════════════════════════

STEP 3: Verify (1 minute)
──────────────────────────

1. Open: https://YOUR-APP-NAME.azurewebsites.net/config.js
   → Should show your Supabase URL (not empty)

2. Open: https://YOUR-APP-NAME.azurewebsites.net
   → Hard refresh: Ctrl+Shift+R
   → Should work without error
